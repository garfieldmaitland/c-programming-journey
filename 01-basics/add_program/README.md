# Add Program

Simple integer addition program - my first C program.

## What I Learned
- Function declarations must come before usage
- '#include <stdio.h>' required for printf()
- Compilation: 'gcc addProgram -o addProgram'
- Execution: './addProgram'


## Errors Encountered
1. Missing stdio.h -> compilation error
2. Function 'add()' not declared before 'main()' -> compilation error
