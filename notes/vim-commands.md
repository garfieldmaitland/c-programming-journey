# VIM Commands to Review

## Basic Navigation
- `h, j, k, l` - left, down, up, right
- `w` - next word
- `b` - previous word

## Modes
- `i` - insert mode
- `ESC` - normal mode
- `:` - command mode

## Save and Quit
- `:w` - save
- `:q` - quit
- `:wq` - save and quit
- `:q!` - quit without saving
